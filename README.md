## Features

* **Lightweight & Fast:**
* **Instance Management:** Keep your save worlds, modpacks, and server configs completely separated.
* **Offline & Online Play:** Streamlined account and session configuration.
* **Good Looking UIs:** The best Minecraft launcher UI you'll ever see.

---

## ⚙️ System Requirements

* **OS:** Linux (Arch / Hyprland compatible), Windows 10/11
* **Java:** JDK / JRE 17 or 21
* **GPU:** Dedicated graphics recommended for shaders and custom client visuals

---

## 🛠️ Building & Running

### Prerequisites

* Git
* Java Development Kit (JDK 17 or 21)

### Build Instructions

```bash
# Clone the repository
git clone [https://github.com/your-username/cooldude515-client.git](https://github.com/your-username/cooldude515-client.git)
cd cooldude515-client

# Grant execution permissions (Linux / macOS)
chmod +x gradlew

# Build the project
./gradlew build
